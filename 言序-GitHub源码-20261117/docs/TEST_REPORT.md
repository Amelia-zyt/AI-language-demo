## 实际限制

没有用真人麦克风进行主观听音或专业发音准确率评估；未覆盖每种手机、全部 BBC 旧节目和离线首次模型下载。BBC 可能有地区限制、外链变化或广告时长差异，因此时间码缓存与实际音频哈希绑定，保留官网入口。系统 TTS 的可用声音由浏览器与操作系统决定。

Whisper 的一致度受漏词、误识别影响；小型 Qwen 的建议可能不准确或不按 JSON 输出，后者安全地显示真实文字建议，不虚构结构化结果。原项目无专业音素评测 API，本次保留此事实。上线多用户服务仍需身份认证；本交付没有配置外部主机或覆盖原公开站点。
